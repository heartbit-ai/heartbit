# Getting Started

This chapter takes you from `cargo new` to a working agent that calls
Claude. By the end you will have:

- a project that depends on `heartbit-core`;
- a 30-line `hello_agent` example that you can run;
- a working understanding of which LLM provider to pick;
- API keys configured for local development.

The chapter has four sub-pages:

- **[Installation](./installation.md)** — adding the crate, Rust
  version, optional features.
- **[Hello agent](./hello-agent.md)** — a minimal agent with a
  walk-through.
- **[Choosing an LLM provider](./providers.md)** — comparison and
  swap-in snippet.
- **[API keys and environment](./env.md)** — where to put secrets
  in dev and in production.

If you already know what provider you want to use and just need the
incantation, jump straight to [Hello agent](./hello-agent.md).
