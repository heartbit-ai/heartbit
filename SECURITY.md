# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest release | Yes |
| Older releases | No |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability in Heartbit, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

### How to Report

1. **Preferred**: Use [GitHub Security Advisories](https://github.com/heartbit-ai/heartbit/security/advisories/new) to report the vulnerability privately.
2. **Alternative**: Email [security@heartbit.ai](mailto:security@heartbit.ai) with details of the vulnerability.

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### Response Timeline

- **72 hours**: Initial acknowledgment of your report
- **7 days**: Assessment and severity classification
- **30 days**: Target for fix release (depending on complexity)

### Important Note

Heartbit is early-stage software under active development. The attack surface is evolving, and we appreciate responsible disclosure to help us improve security as the project matures.

We will credit reporters in the release notes (unless you prefer to remain anonymous).
