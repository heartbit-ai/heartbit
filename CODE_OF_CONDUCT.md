# Code of Conduct

## Be Professional

This project is a professional collaboration space. We expect participants to:

- **Be respectful** — disagree on ideas, not people.
- **Be constructive** — if you see a problem, propose a solution.
- **Be direct** — say what you mean. Don't waste people's time.
- **Be helpful** — share knowledge, review thoughtfully, answer questions.
- **Take responsibility** — own your mistakes, fix them, move on.

## Not Tolerated

- Personal attacks, insults, or harassment.
- Spam, trolling, or deliberately disruptive behavior.
- Publishing others' private information without consent.

## Enforcement

Violations can be reported to security@heartbit.ai. Maintainers will review and take appropriate action, which may include warnings or permanent bans. Decisions are final.

## Scope

This applies to all project spaces: issues, PRs, discussions, chat, and events.
